The skydive rig is a wardrobe configuration rather than one person's
outfit: it belongs to the activity. Whoever jumps wears this, so continuity
holds if the campaign recasts the leap — change the character, keep the rig.

Name it in a shot line ("…wearing the skydive rig and Vista Air") to
compose it. It is deliberately absent from every character's default
wardrobe.
